# 架构

## 一句话

一个**可信宿主** + 一组**不可信插件** + 一层**只读 API 白名单**。

```
┌──────────────────────── 控制台（私有） ────────────────────────┐
│  /api/overview  /api/stats  /api/config ...                    │
│        ▲                                                       │
│        │ fetch（同源，宿主自己做）                              │
│  ┌─────┴──────────────────────────────────────────────────┐    │
│  │ 插件宿主（本仓库 plugins/）                             │    │
│  │  · registry.js 清单                                    │    │
│  │  · gallery.js 沙箱 / 权限 / postMessage                 │    │
│  │  · sdk.js 给插件用                                     │    │
│  └─────┬──────────────────────────────────────────────────┘    │
│        │ postMessage（跨源，唯一的通道）                        │
│  ┌─────▼──────────────────────────────────────────────────┐    │
│  │ 插件 iframe（sandbox，无 same-origin）                  │    │
│  │  任意 HTML/CSS/JS；拿不到父页 DOM/cookie/token          │    │
│  └────────────────────────────────────────────────────────┘    │
└────────────────────────────────────────────────────────────────┘
```

## 为什么用 iframe

插件可能是第三方的、AI 生成的、从网上下载的。`import()` 进主程序会给它完整权限；iframe 是浏览器里最小、最成熟的隔离边界。

代价：

- 插件不能直接复用主程序的组件，要自己带 CSS；
- 通信只能 `postMessage`，异步；
- 样式不能继承，需要自己定义主题变量。

收益：

- 插件拿不到 `document.cookie`、`localStorage`、主程序 token；
- 插件崩了不影响宿主；
- 插件可以用任何栈（原生、React、Vue、SVG、Canvas），宿主不关心。

## 消息协议

插件 → 宿主：

```json
{ "qiyu": 1, "id": 3, "method": "overview.get", "params": {} }
```

宿主 → 插件：

```json
{ "qiyu": 1, "id": 3, "ok": true, "data": { "心情": 70 } }
{ "qiyu": 1, "id": 3, "ok": false, "error": "缺少权限 overview:read" }
```

握手：

```json
{ "qiyu": 1, "type": "ready" }
{ "qiyu": 1, "type": "hello", "plugin": { "id": "rhythm", "permissions": ["overview:read"] } }
```

## 权限

`registry.js` 里的 `permissions` 是插件的声明；宿主的方法表是唯一执行点：

- 方法不在表里 → 拒绝；
- 方法需要权限、插件没声明 → 拒绝；
- 读 API 由宿主 fetch，插件永远不直接拿 `fetch('/api/...')`。

## 演示

`demo/server.mjs` 用内存假数据替换 `/api/*`，把宿主 + 示例插件跑在 `127.0.0.1:7800`。它不依赖控制台，方便看视觉和调试。

## 不在本仓库

QQ/NapCat、角色人格、记忆库、手机控制、语音权重、第三方补丁。这些属于私人运行时，见私有仓库；公开层只保留可复用的插件框架。
